Smart Expense Tracker

A simple Python-based expense tracker to record, filter, summarize, and visualize spending.

 Features

Add and validate expenses

Filter by category, date, or amount

Calculate total & average spending

Generate category-wise reports

Analyze monthly spending

Visualize expenses with Matplotlib & Seaborn

 Tech Stack

Python · Pandas · NumPy · Matplotlib · Seaborn

 Run

pip install pandas numpy matplotlib seaborn

Open _Smart_Expense_Tracker.ipynb in Jupyter Notebook/JupyterLab and run the cells.
